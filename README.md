# 🏨 Hotel Management System

A database project developed using **MySQL** to manage hotel information and perform database operations.

## 📌 Project Overview

The Hotel Management System demonstrates how SQL can be used to create and manage a hotel database, store records, and retrieve information through queries.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Command Line (CMD)

## 📂 Project Files

- `hotel_management.sql` — Contains the SQL commands used in the project.

## ✨ Key Features

- Database and table creation
- Inserting records
- Retrieving data using SQL queries
- Updating existing records
- Deleting records
- Performing database operations using MySQL

## 🚀 How to Run

1. Install MySQL on your system.
2. Open MySQL Command Line.
3. Execute the SQL commands in `hotel_management.sql`.
4. Run the queries to explore the database operations.

## 🎯 Project Objective

To gain practical experience in SQL, database management, and relational database operations.
